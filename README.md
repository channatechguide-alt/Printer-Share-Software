## 🔧 Common Printer Errors

Printer Share Toolkit can help troubleshoot issues related to common Windows printer-sharing and network connection errors, including:

* `0x0000011B`
* `0x00000709`
* `0x00000006`
* `0x80070035`

> The exact cause of a printer error can vary depending on the Windows configuration, network, printer driver, permissions, and sharing settings.

## 🌐 Typical Network Setup

A common printer-sharing setup looks like this:

```text
┌──────────────────┐
│  Main PC /       │
│  Printer Server  │
└────────┬─────────┘
         │
      Local LAN
         │
   ┌─────┴─────┐
   │           │
┌──▼───┐   ┌──▼───┐
│ PC 1 │   │ PC 2 │
└──────┘   └──────┘
```

The printer is connected to one Windows PC and shared with other computers through the local network.

## ⚙️ How to Use

1. Download the latest **PrinterShareToolkit.exe**.
2. Run the application on your Windows PC.
3. Follow the available printer-sharing or troubleshooting options.
4. Make sure the required PCs are connected to the same local network.
5. Test the printer connection from the client PC.

> Some Windows settings may require Administrator privileges.

## 📌 Important

* This tool is intended for **Windows 10 and Windows 11**.
* Printer drivers and Windows networking configuration can affect printer connectivity.
* Make sure you have permission to modify printer and network settings on the computer.
